Challenges 8–10 — Write the Code

8. Multiples of Four Medium

Write a for loop that prints every multiple of 4 from 1 to 40, each on its own line.

Expected output:  4   8   12   16   20   24   28   32   36   40  (each on a separate line)

Hint: use range(), for, %, and if.
9. Interactive Greeter Medium

Write a program that:

  1. Asks the user for their name.
  2. Asks for their favorite number and converts it to an integer.
  3. Prints:  Hello, [name]! Your lucky number doubled is [n].
Hint: use input(), int(), str(), and +.
10. Digit Puzzle Solver Intermediate

Find every two-digit number from 10 to 99 where the tens digit plus the units digit equals 9 and both digits are different. Print each one.

Expected output:  18   27   36   45   54   63   72   81   90  (each on a separate line)

Hint: use range(10, 100), a list comprehension with str(n).zfill(2) to get digits, then check your conditions with and.

Each challenge is a small, fun program. Write your code in the space below each one, or on a computer. You can use the Python Quick Reference sheet for help.

11. 🎱 Magic 8-Ball Easy

Ask the user to type a yes/no question. Pick a random mystical answer from a list and print it. Run it a few times — the answer should be different each time!

Example output:  🎱 Signs point to yes.

12. 🐾 Virtual Pet Mood Tracker Easy

Use: input()   int()   if / elif / else
13. 🎨 Color Mixer Medium

Ask for two color names. Look up the pair in a dictionary of combos and print a fun result. Handle the case where the combo isn't in the dictionary.

14. 🔐 Secret Message Encoder Medium

15. 🎲 Dice Duel Medium

You vs. the computer, 5 rounds. Each round, roll a random die (1–6). Keep running totals. At the end, print the scores and declare a winner.

Example round:  Round 3: You rolled 5, Computer rolled 2 — You win!
