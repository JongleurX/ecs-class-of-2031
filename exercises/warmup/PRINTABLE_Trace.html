Quick Self-Check Rules

  • range(start, stop) includes start and excludes stop.
  • Fill one table row per loop pass.
  • Always separate before vs after values.
  • For nested loops, trace outer loop first, then inner loop for each outer pass.
  • Match spacing, punctuation, and capitalization exactly in predicted output.
