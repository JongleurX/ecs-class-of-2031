Round A — Variables & Print
Key idea: a variable is a named box; print() shows its contents.
Snippet 1 — Variables + print name = "Avery" / score = 3
name = "Avery" score = 3 print(name, "has", score, "points")
Expected output
Avery has 3 points
Accepted modifications
score = 6 — or — score = score * 2
Common mistakes
  • Writing score * 2 in the print call — valid Python, but the goal says change the variable assignment
  • Forgetting quotes around string arguments in print()
  • Expecting output Avery has 3 * 2 points — multiplication is not shown literally
Hint Ladder (give only if stuck)
Hint 1 Look at the line that says score = 3. What number is double 3?
Hint 2 Change just the number after score =. You only need to edit that one line.
Hint 3 (reveal) Replace line 2 with score = 6. Output becomes Avery has 6 points.
Snippet 2 — Arithmetic expression z = x + y * 3
x = 4 y = 2 z = x + y * 3 print(z)
Expected output
10
4 + (2×3) = 4 + 6 = 10 — order of operations!
Accepted modifications (output 18)
z = 18 or change x/y/operator so result = 18 x = 6 → 6 + 2*3 = 12 ✗ (not 18) z = x * y * 3 → 4*2*3 = 24 ✗ z = (x + y) * 3 → 18 ✓
Common mistakes
  • Predicting 18 for the original code — forgetting order of operations (multiplication before addition)
  • Trying to change print(z) to print(18) — technically works but misses the point
  • Adding parentheses incorrectly: (x + y) * 3 is a great find — praise it!
Hint Ladder
Hint 1 Python does multiplication before addition. Recalculate: y * 3 first, then add x.
Hint 2 To get 18, think: what two numbers multiply to 18? Can you use x and y? Try adding parentheses.
Hint 3 (reveal) Change line 3 to z = (x + y) * 3. That gives (4+2)×3 = 18.
Round B — Strings & Conditionals
Key idea: + joins strings; if/else picks a branch based on a condition.
Snippet 3 — String concatenation word = "Py" + "thon"
word = "Py" word = word + "thon" print(word)
Expected output
Python
Accepted modifications (output Python!)
word = word + "thon!" — or — word = word + "thon" + "!"
Common mistakes
  • Adding ! as a separate line after print — print(word + "!") works but changes line 3, not line 2
  • Typing "thon" + "!" without re-reading which line to change
  • Forgetting the quotes around "!"
Hint Ladder
Hint 1 Look at line 2. The + glues pieces of text together. How would you glue ! onto the end?
Hint 2 Add + "!" somewhere on line 2, inside the quotes or after them.
Hint 3 (reveal) Change line 2 to word = word + "thon!". Output: Python!
Snippet 4 — if / else temp = 72 → "Comfortable"
temp = 72 if temp > 75: print("Hot") else: print("Comfortable")
Expected output
Comfortable
72 > 75 is False → else branch runs
Accepted modifications (print Hot)
Any temp > 75: temp = 76 ✓ temp = 100 ✓ temp = 75 ✗ (not strictly >)
Common mistakes
  • Setting temp = 75 — the condition is > (strictly greater), so 75 prints Comfortable
  • Changing the > to >= instead of changing temp — valid, but the goal says change only the value
  • Predicting Hot for the original — not checking the comparison carefully
Hint Ladder
Hint 1 The condition on line 2 says temp > 75. Is 72 greater than 75?
Hint 2 To enter the if branch, temp must be more than 75. Change line 1 to a number bigger than 75.
Hint 3 (reveal) Change line 1 to temp = 80. Now 80 > 75 is True, so Python prints Hot.
Round C — Loops
Key idea: range(n) counts from 0 up to (but not including) n; accumulator keeps a running total.
Snippet 5 — for loop range(3) → Hi 0, Hi 1, Hi 2
for i in range(3): print("Hi", i)
Expected output (3 lines)
Hi 0 Hi 1 Hi 2
Accepted modification (5 lines)
for i in range(5): print("Hi", i)
Common mistakes
  • Predicting output starts at 1 — range(3) starts at 0, not 1
  • Using range(1, 5) — produces 4 lines (1,2,3,4), not 5
  • Confusing number of iterations with the final value of i
Hint Ladder
Hint 1 range(3) gives three numbers: 0, 1, 2. The loop runs once per number. How many numbers does range(5) give?
Hint 2 To get 5 lines, change the number inside range( ) to 5.
Hint 3 (reveal) Change line 1 to for i in range(5):. Output: Hi 0 through Hi 4 — five lines total.
Snippet 6 — Accumulator loop range(1, 4) → total = 6
total = 0 for n in range(1, 4): total = total + n print(total)
Expected output
6
1 + 2 + 3 = 6  (range stops before 4)
Accepted modification (output 10)
range(1, 5) → 1+2+3+4 = 10 ✓
Common mistakes
  • Predicting total = 10 for original — forgetting range(1, 4) stops at 3, not 4
  • Using range(1, 10) — sum is 45, far more than 10
  • Using range(4) — sums 0+1+2+3 = 6, not 10
  • Thinking range(1, 5) includes 5 — it stops before the end value
Hint Ladder
Hint 1 range(1, 4) produces 1, 2, 3 (stops before 4). Add them: 1+2+3 = ? Now what numbers add up to 10?
Hint 2 1+2+3+4 = 10. So you need the loop to reach 4. What second number in range(1, ?) would let it include 4?
Hint 3 (reveal) Change line 2 to for n in range(1, 5):. The loop runs for 1, 2, 3, 4 → total = 10.

Whole-class debrief talking points

  • Snippet 2 — Order of operations: Ask students what they predicted and why. Many will say 18. Use this to introduce that Python (like math) does * before +.
  • Snippet 4 — Off-by-one on condition: Ask what happens with temp = 75. Use it to contrast > vs >=.
  • Snippet 5 — Zero-indexing: Point out that range(3) starts at 0. Foreshadows list indexing later.
  • Snippet 6 — range upper bound is exclusive: A recurring Python "gotcha." The mnemonic: range goes up to, but doesn't include, the stop value.
  • Code.org verify: Circulate while students type snippets in. Remind them to predict on paper before running, not after. The paper prediction is the key cognitive move.
  • Goal round: Students only change one or two lines in Code.org — they do not write the modified code on the worksheet. Keeping it digital speeds iteration and removes fear of erasing.
