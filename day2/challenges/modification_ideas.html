Syntax Challenge Mod Ideas Bank

Use this when students pick a challenge but are not sure what to change. Start with one easy mod, then stack a medium/harder mod.

Challenge 11: Magic 8-Ball

  • Very EasyAdd 5 new responses to the responses list (funny, mysterious, or school-themed).
  • EasyIf the question does not end with a ?, print a reminder first, then still answer.
  • MediumUse response categories (yes / maybe / no) and print the category with the answer.
  • Somewhat ChallengingLet the user ask 3 questions in a loop and show how many answers were positive, neutral, or negative.

Challenge 12: Virtual Pet Mood Tracker

  • Very EasyRename Biscuit and customize all mood messages for a different pet.
  • EasyAdd an input check so negative feeding counts become 0.
  • MediumTrack two things: times_fed and minutes_played, then combine them for mood logic.
  • Somewhat ChallengingRun a 3-day tracker loop and print an overall summary (average feedings + mood each day).

Challenge 13: Color Mixer

  • Very EasyAdd 4 new color combinations to the combos dictionary.
  • EasyHandle same-color mixes (for example, red + red).
  • MediumAllow users to mix colors repeatedly until they type quit.
  • Somewhat ChallengingAdd a "favorite mix" counter that tracks how often each valid combo is used.

Challenge 14a: Secret Message Encoder

  • Very EasyChange shift from 3 to 5 and update the docstring example.
  • EasyLet the user choose a shift value (1-25).
  • MediumPreserve spaces/punctuation (already done) and also print letter count statistics.
  • Somewhat ChallengingAdd a mode that can encode multiple messages in a loop and save them to a list before printing all results.

Challenge 14b: Secret Message Decoder

  • Very EasySwap hidden input to regular input() for easier debugging mode.
  • EasyAllow custom shift input so user can decode messages not shifted by 3.
  • MediumAfter decoding, ask "encode back to verify?" and show round-trip check.
  • Somewhat ChallengingTry all 25 shifts automatically and print every possible decode (mini brute-force helper).

Challenge 15: Dice Duel

  • Very EasyIncrease the duel to 7 rounds and update messages.
  • EasyAdd a "double points" round (for example, round 3 counts twice).
  • MediumLet user choose number of rounds and die size (6-sided, 8-sided, 20-sided).
  • Somewhat ChallengingAdd critical events: rolling max gives a bonus point, rolling 1 loses a point (never below 0).

Challenge 16: Mood-Based Activity Suggester

  • Very EasyAdd 3 new mood keyword groups and suggestions.
  • EasyAsk for time available (5, 15, 30+ minutes) and tailor the suggestion length.
  • MediumGive two suggestions and let the user pick one, then print a mini action plan.
  • Somewhat ChallengingStore mood check-ins in a list and print a mood summary after 5 entries.

Challenge 17: Pizza Order Builder

  • Very EasyAdd one new size and base price (for example, personal or XL).
  • EasyAdd topping prices that differ by topping instead of flat $1.50.
  • MediumAdd discount rules (for example, 10% off if 3 toppings).
  • Somewhat ChallengingSupport multiple pizzas in one order and print grand total + itemized receipt.

Challenge 18: Trivia Quiz

  • Very EasyAdd 3 new questions to the list.
  • EasyAccept alternate correct answers for one question (for example, "purple" or "violet").
  • MediumShuffle question order each run and track which were missed.
  • Somewhat ChallengingAdd category selection (math/science/misc) and load only that subset.

Challenge 19: Name Scrambler

  • Very EasyUppercase the scrambled result and add decorative symbols.
  • EasyReject blank names and ask again until valid input.
  • MediumGenerate 5 different scrambles and print the shortest and longest (same length here, but still good practice).
  • Somewhat ChallengingScramble each word separately for full names (first and last names stay as two words).

Challenge 20: Compliment Machine

  • Very EasyAdd 5 new adjectives, 3 new nouns, and 3 new extras.
  • EasyAsk for how many compliments to generate (1-5) and print that many.
  • MediumAvoid repeating adjectives in a single run by removing used choices temporarily.
  • Somewhat ChallengingAdd compliment "themes" (space, sports, school) with separate word lists and user-selected theme.
Teacher tip: Have students pick one mod from "Very Easy/Easy" first, commit it, test it, then pick one "Medium/Somewhat Challenging" mod and iterate.
