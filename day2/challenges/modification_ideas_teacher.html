Syntax Challenge Mod Hint Snippets

Quick teacher helper: each mod has a tiny outline snippet (not full solution code) so you can unblock students fast.

Challenge 11: Magic 8-Ball

Very Easy
Add extra responses.
responses.extend([
    "Absolutely yes.",
    "No chance.",
    "Try tomorrow.",
])
Easy
Check for a question mark.
question = input("Ask: ")
if not question.strip().endswith("?"):
    print("Tip: Ask as a question ending with ?")
Medium
Use response categories.
yes = ["It is certain."]
maybe = ["Ask again later."]
no = ["Very doubtful."]
category = random.choice(["yes", "maybe", "no"])
Somewhat Challenging
Ask 3 questions and count categories.
counts = {"yes": 0, "maybe": 0, "no": 0}
for _ in range(3):
    input("Ask: ")
    c = random.choice(["yes", "maybe", "no"])
    counts[c] += 1

Challenge 12: Virtual Pet Mood Tracker

Very Easy
Customize pet name and mood lines.
pet_name = "Mochi"
if times_fed == 0:
    mood = f"{pet_name} is hungry!"
Easy
Clamp negative input to 0.
times_fed = int(input("Fed times: "))
if times_fed < 0:
    times_fed = 0
Medium
Combine feeding + play time.
play_minutes = int(input("Play minutes: "))
if times_fed <= 1 and play_minutes < 10:
    mood = "Needs attention"
elif times_fed <= 3 and play_minutes >= 10:
    mood = "Very happy"
Somewhat Challenging
Track 3 days and summarize.
feed_log = []
for day in range(1, 4):
    feed_log.append(int(input(f"Day {day}: ")))
avg = sum(feed_log) / len(feed_log)
print("Average fed:", avg)

Challenge 13: Color Mixer

Very Easy
Add more combos.
combos[("green", "white")] = "Mint"
combos[("red", "black")] = "Maroon"
Easy
Handle same-color mixes.
if color1 == color2:
    print("Double", color1, "->", color1.capitalize())
else:
    print(combos.get((color1, color2), "Unknown"))
Medium
Repeat until quit.
while True:
    c1 = input("Color 1 (or quit): ").lower().strip()
    if c1 == "quit":
        break
    c2 = input("Color 2: ").lower().strip()
Somewhat Challenging
Track most-used mix.
mix_counts = {}
key = (c1, c2)
mix_counts[key] = mix_counts.get(key, 0) + 1
print("Used", key, mix_counts[key], "times")

Challenge 14a: Secret Message Encoder

Very Easy
Change shift value.
SHIFT = 5
encoded += chr((ord(ch) - base + SHIFT) % 26 + base)
Easy
Let user choose shift.
shift = int(input("Shift 1-25: ")) % 26
encoded += chr((ord(ch) - base + shift) % 26 + base)
Medium
Count encoded letters.
letters_changed = 0
if ch.isalpha():
    letters_changed += 1
print("Letters encoded:", letters_changed)
Somewhat Challenging
Encode multiple messages.
outputs = []
while True:
    msg = input("Message (blank to stop): ")
    if msg == "":
        break
    outputs.append(encode(msg, shift))

Challenge 14b: Secret Message Decoder

Very Easy
Toggle hidden input.
debug = True
if debug:
    encoded = input("Paste encoded: ")
else:
    encoded = getpass.getpass("Paste encoded: ")
Easy
Custom decode shift.
shift = int(input("Decode shift: ")) % 26
decoded += chr((ord(ch) - base - shift) % 26 + base)
Medium
Round-trip verify.
decoded = decode(encoded, shift)
check = encode(decoded, shift)
print("Round-trip matches:", check == encoded)
Somewhat Challenging
Try all shifts.
for s in range(1, 26):
    candidate = decode(encoded, s)
    print(s, "->", candidate)

elif "angry" in mood or "mad" in mood:

Challenge 19: Name Scrambler

Very Easy
Uppercase output styling.
scrambled = "".join(letters).upper()
print("***", scrambled, "***")
Easy
Reject blank input.
name = input("Name: ").strip()
while name == "":
    name = input("Please enter a name: ").strip()
Medium
Generate 5 unique scrambles.
results = set()
while len(results) < 5:
    letters = list(name)
    random.shuffle(letters)
    results.add("".join(letters))
Somewhat Challenging
Scramble each word separately.
parts = name.split()
out = []
for part in parts:
    letters = list(part)
    random.shuffle(letters)
    out.append("".join(letters))

Theme-based compliments.
themes = {
