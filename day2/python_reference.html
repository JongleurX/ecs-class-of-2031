List Comprehensions

A compact [ expr for var in iterable ] that builds a list in one line.

# Long way:
squares = []
for x in range(5):
    squares.append(x * x)  # [0, 1, 4, 9, 16]

# Short way:
squares = [x * x for x in range(5)]

# Convert digit chars to ints:
digits = [int(c) for c in "123"]   # [1, 2, 3]

# With a condition:
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

enumerate() — index + value

Adds an automatic counter to any loop.

animals = ["cat", "dog", "rabbit"]

# Start from 1:
for i, animal in enumerate(animals, start=1):
    print(f"{i}. {animal}")

Caesar Cipher (Day 3)

Shift each letter by 3, wrapping with % 26.

message = input("Message: ")
encoded = ""
for ch in message:
    if ch.isalpha():
        base = ord("A") if ch.isupper() else ord("a")
        encoded += chr((ord(ch) - base + 3) % 26 + base)
    else:
        encoded += ch
print("Encoded:", encoded)

For "D": 3 + 3 = 6 → chr(71) = "G". Decode: use -3.
