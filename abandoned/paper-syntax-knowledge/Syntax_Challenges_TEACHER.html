8. Multiples of FourMedium
for n in range(1, 41):
    if n % 4 == 0:
        print(n)
Prints 4, 8, 12 … 40. range(1, 41) stops before 41, so 40 is included. The % check filters to multiples of 4.
9. Interactive GreeterMedium
name = input("What is your name? ")
num  = int(input("Favorite number? "))
print("Hello, " + name + "! Your lucky "
      + "number doubled is "
      + str(num * 2) + ".")
input() always returns a string, so int() is required before arithmetic. str() is required before string concatenation.
10. Digit Puzzle SolverIntermediate
for n in range(10, 100):
    d = [int(c) for c in str(n).zfill(2)]
    if d[0] + d[1] == 9 and d[0] != d[1]:
        print(n)
Output: 18, 27, 36, 45, 54, 63, 72, 81, 90. The list comprehension converts each digit character to an integer. d[0] != d[1] excludes cases where both digits are the same (none exist here, but the condition is correct). Students who just used len(set(d)) == 2 are also correct.
